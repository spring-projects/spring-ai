[[openai]]
= OpenAI

The `spring-ai-openai` module integrates the OpenAI platform.
Add the `spring-ai-starter-model-openai` starter to auto-configure it.

All OpenAI model types share the same connection properties, `spring.ai.openai.api-key` and `spring.ai.openai.base-url`.
xref:integrations/models/openai/chat.adoc[OpenAI Chat] describes how to obtain an API key and how to manage it.
