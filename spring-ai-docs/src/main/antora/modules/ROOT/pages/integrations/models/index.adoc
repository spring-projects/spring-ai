== Other Ways to Reach a Model

* Services and local servers that expose an OpenAI-compatible API, such as Groq, NVIDIA, Perplexity and Docker Model Runner, are used through the OpenAI module.
See xref:integrations/models/openai-compatible/index.adoc[OpenAI-Compatible Endpoints].
* OpenAI models deployed on Azure are used through the OpenAI module.
See xref:integrations/models/openai/azure.adoc[Azure and Microsoft Foundry].
* Integrations maintained outside the Spring AI repository are listed under xref:integrations/community/index.adoc[Community-Maintained Integrations].
