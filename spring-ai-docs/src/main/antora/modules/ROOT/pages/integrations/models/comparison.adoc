[[chat-model-comparison]]
= Chat Model Comparison
:page-aliases: api/chat/comparison.adoc

The table compares the chat model integrations of Spring AI:

* *Input*: what the model accepts besides text, see xref:multimodality.adoc[Multimodality].
* *Tool calling*: whether the model can call xref:tools/index.adoc[tools].
* *Streaming*: whether the model can stream its answer.
* *Retry*: whether failed calls are retried, see xref:resilience/retry.adoc[Retry].
* *Observability*: whether the model reports metrics and traces, see xref:observability/index.adoc[Observability].
* *Native structured output*: whether the chat options support xref:structured-output/native.adoc[provider-native structured output].
* *Local*: whether the model can run on your own machine.
* *OpenAI-compatible*: whether the service also offers an OpenAI-compatible API.

Services that are used through another module, such as the OpenAI module, use the chat options of that module.
Whether they honor native structured output, or an option of the original provider, depends on the service.
