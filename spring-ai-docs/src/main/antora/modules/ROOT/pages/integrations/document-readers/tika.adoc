= Tika (DOCX, PPTX, HTML...)
The `TikaDocumentReader` uses Apache Tika to extract text from a variety of document formats, such as PDF, DOC/DOCX, PPT/PPTX, and HTML.
For a comprehensive list of supported formats, refer to the https://tika.apache.org/docs/4.0.x/formats.html[Tika documentation].

== Dependencies
Add the dependency to your project using Maven or Gradle.

[tabs]
======
Maven::
+
[source, xml]
----
<dependency>
    <groupId>org.springframework.ai</groupId>
    <artifactId>spring-ai-tika-document-reader</artifactId>
</dependency>
----

Gradle::
+
[source,groovy]
----
dependencies {
    implementation 'org.springframework.ai:spring-ai-tika-document-reader'
}
----
======

== Example

[source,java]
----
@Component
class MyTikaDocumentReader {

    private final Resource resource;

    MyTikaDocumentReader(@Value("classpath:/word-sample.docx")
                            Resource resource) {
        this.resource = resource;
    }

    List<Document> loadText() {
        TikaDocumentReader tikaDocumentReader = new TikaDocumentReader(this.resource);
        return tikaDocumentReader.read();
    }
}
----

== Limiting the extracted text

The extracted text is held in memory, so the reader extracts at most `TikaDocumentReader.DEFAULT_MAX_CHARACTERS` (10,000,000) characters per document and throws an `IllegalStateException` if a document exceeds that limit.
This prevents a large document from exhausting the JVM heap.

The limit is an absolute ceiling and complements the guard Apache Tika applies on its own.
Tika rejects a document whose extracted text is disproportionate to its input, but that guard is relative to the size of the input, so a large enough input can still expand to an arbitrary amount of text without tripping it.

Pass an explicit limit to read larger documents, or `-1` to disable the limit altogether.
Because the extracted text is held in memory, disabling the limit is only safe for documents from trusted sources.

[source,java]
----
List<Document> loadText() {
    TikaDocumentReader tikaDocumentReader = new TikaDocumentReader(this.resource, 20_000_000,
            ExtractedTextFormatter.defaults());
    return tikaDocumentReader.read();
}
----

The limit bounds the extracted text, not the size of the input.
When documents come from untrusted sources, also bound the size of the input itself, for example with the `spring.servlet.multipart.max-file-size` property for uploads.
