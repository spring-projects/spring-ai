[[modules]]
= Modules and Starters

This page lists the modules published by Spring AI, all under the `org.springframework.ai` group.
Import the `spring-ai-bom` to manage their versions, as described in xref:get-started/project-setup.adoc#dependency-management[Dependency Management].

== Core Modules

[cols="2,3", options="header"]
|===
| Artifact | Description

| `spring-ai-bom`
| Bill of Materials POM (BOM) for the Spring AI modules

| `spring-ai-client-chat`
| Spring AI Chat Client AI programming

| `spring-ai-commons`
| Common classes used across Spring AI

| `spring-ai-model`
| Core model interfaces and classes for Spring AI

| `spring-ai-rag`
| Retrieval Augmented Generation (RAG) support for Spring AI

| `spring-ai-retry`
| Spring AI utility project helping with remote call retry

| `spring-ai-session`
| Spring AI session memory: an append-only conversation log with compaction

| `spring-ai-spring-boot-docker-compose`
| Spring AI Docker Compose

| `spring-ai-spring-boot-testcontainers`
| Spring AI Testcontainers

| `spring-ai-template-st`
| StringTemplate implementation for Spring AI templating

| `spring-ai-test`
| Test support for AI programming

| `spring-ai-tool-search-tool`
| API types for the Tool Search Tool: ToolIndex interface and related model classes

| `spring-ai-vector-store`
| Common vector store functionality for Spring AI

|===
